# Akash — Birthday Surprise 🎂

A cinematic, mobile-first birthday experience built for September 9, 2026.

## Customize

Everything personal lives in `src/data.js`: traits, memories, wishes, and the final message. Add real photos to `public/images/` using the filenames in the memories array. Optional music can be added at `public/audio/birthday.mp3`.

## Run

```bash
npm install
npm run dev
```

Build with `npm run build`.
